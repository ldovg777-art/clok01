### ⚠️ Обнаруженные проблемы

#### 1. Неправильный тип узла `ui_ui_control`
**Файлы:** Все файлы flows
**Строка:** ~41
**Проблема:** Используется тип `ui_ui_control`, что может быть опечаткой. В Node-RED Dashboard правильный тип должен быть `ui_base` (для базовой конфигурации) или узел может отсутствовать вообще.

**Текущий код:**
```json
{
  "id": "c6afcb9a79a54d5d",
  "type": "ui_ui_control",
  ...
}
```

**Рекомендация:** Проверить документацию Node-RED Dashboard для версии 3. Возможно, этот узел устарел или имеет другое название.

#### 2. Неправильный синтаксис Jsonata для flow context
**Файлы:** Все файлы flows
**Строка:** ~192
**Проблема:** Используется `$flowContext()` в Jsonata, но правильный синтаксис для доступа к flow context в Node-RED 3 может отличаться.

**Текущий код:**
```json
"to": "$flowContext('version') & ($flowContext('versionTime') ? ' ' & $flowContext('versionTime') : '')"
```

**Рекомендация:** 
- Для Node-RED 3 с Jsonata использовать: `$flowContext("version") & ($flowContext("versionTime") ? " " & $flowContext("versionTime") : "")`
- Или использовать двойные кавычки вместо одинарных
- Или рассмотреть использование встроенной функции Node-RED вместо Jsonata

#### 3. Отсутствие проверки совместимости узлов
**Проблема:** Код использует узлы Dashboard, но не указано, какая версия `node-red-dashboard` используется. Для Node-RED 3 требуется совместимая версия dashboard.

**Рекомендация:** Убедиться, что используется `node-red-dashboard` версии 3.x или совместимая версия.
