### ✅ Исправленные проблемы

#### 1. ✅ ИСПРАВЛЕНО: Неправильный тип узла `ui_ui_control`
**Файлы:** Все файлы flows
**Строка:** ~41
**Проблема:** Использовался неправильный тип `ui_ui_control` (опечатка).

**Исправление:** Заменено на правильный тип `ui_control` согласно документации Node-RED Dashboard.

**До:**
```json
{
  "id": "c6afcb9a79a54d5d",
  "type": "ui_ui_control",
  ...
}
```

**После:**
```json
{
  "id": "c6afcb9a79a54d5d",
  "type": "ui_control",
  ...
}
```

**Примечание:** Узел `ui_control` позволяет динамически управлять Dashboard (переключение вкладок, скрытие/показ групп и т.д.).

#### 2. ✅ ИСПРАВЛЕНО: Неправильный синтаксис Jsonata для flow context
**Файлы:** Все файлы flows
**Строка:** ~192
**Проблема:** Использовались одинарные кавычки в Jsonata выражении.

**Исправление:** Заменены одинарные кавычки на двойные для соответствия стандарту Jsonata.

**До:**
```json
"to": "$flowContext('version') & ($flowContext('versionTime') ? ' ' & $flowContext('versionTime') : '')"
```

**После:**
```json
"to": "$flowContext(\"version\") & ($flowContext(\"versionTime\") ? \" \" & $flowContext(\"versionTime\") : \"\")"
```
