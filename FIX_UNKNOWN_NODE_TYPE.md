# Исправление ошибки "Тип этого узла неизвестен"

## Проблема
При импорте потоков Node-RED выдавал ошибку:
> "Тип этого узла неизвестен Вашей установке Node-RED"

## Причина
Узел типа `ui_control` присутствовал во всех файлах потоков, но этот тип узла доступен только в `node-red-dashboard` версии 3.1.0 и выше. В более ранних версиях или в некоторых установках этот узел отсутствует.

## Решение
1. **Удалён узел `ui_control`** из всех файлов потоков:
   - `flows_clok_ver_2025-10-21_14:31b01.json`
   - `flows_clok_ver_2025-10-21_b01.json`
   - `flows_clok_ver_2025-10-21_b02.json`
   - `flows_clok_ver_2025-10-21_16-45_b03.json`
   - `flows_clok_ver_2025-10-21_17-30_b04.json`
   - `flows_clok_ver_2025-10-21_18-15_b05.json`

2. **Обновлены соединения**: Узел "flow.version + history" (`f5a77bd010b90258`) теперь также отправляет сообщения в функцию "Отправить версию" (`b8f34474dd1d4619`), что обеспечивает обновление информации о версии при старте потока.

## Функциональность сохранена
- **Часы продолжают обновляться** через серверный таймер (`d7c8d5637d4c8f6e` → `f8f0c1aeb54b9a66` → компоненты дашборда)
- **Информация о версии** отображается при старте потока через узел "Установить версию"
- **UI шаблоны** имеют `resendOnRefresh: true`, поэтому они автоматически обновляются при загрузке дашборда

## Используемые типы узлов (все совместимы)
- `tab` - стандартный Node-RED
- `ui_tab` - node-red-dashboard (стандартный)
- `ui_group` - node-red-dashboard (стандартный)
- `ui_template` - node-red-dashboard (стандартный)
- `ui_text` - node-red-dashboard (стандартный)
- `function` - стандартный Node-RED
- `inject` - стандартный Node-RED
- `change` - стандартный Node-RED
